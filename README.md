# ShopZone — Comercio Electrónico 🛍️

Una tienda online atractiva y completamente funcional desarrollada con HTML, CSS y JavaScript puro.

## 🚀 Características

- **Página de inicio** atractiva con hero animado, categorías y productos destacados
- **Catálogo de productos** con filtros por categoría, búsqueda y ordenamiento
- **Carrito de compras** persistente (localStorage) con sidebar deslizable y página dedicada
- **Lista de favoritos** (wishlist) con persistencia
- **Cuenta regresiva** para ofertas especiales
- **Newsletter** con formulario de suscripción
- **Diseño responsive** para móviles, tabletas y escritorio
- **Notificaciones toast** para feedback de acciones

## 📂 Estructura

```
E_coomerce/
├── index.html       # Página principal
├── products.html    # Catálogo de productos
├── cart.html        # Carrito de compras
├── styles.css       # Estilos (CSS variables, responsive)
└── app.js           # Lógica del carrito, productos, filtros
```

## 🎨 Tecnologías

- HTML5 semántico
- CSS3 (variables, Grid, Flexbox, animaciones)
- JavaScript ES6+ (sin dependencias externas)
- localStorage para persistencia del carrito

## 🌐 Uso

Abre `index.html` en cualquier navegador moderno. No requiere servidor ni compilación.
